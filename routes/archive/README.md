# 過去路線の停留所座標

28（札幌ターミナル→あいの里4条1丁目）、東64の往復、西66を過去路線として収録しています。
CSV v2の「緯度」「経度」列を使用します。放送指定・運賃・停留所順は保持しています。

83停留所分（同じ停留所を通る路線別の重複を含む）のうち、71件は入力GTFSの同名停留所の座標を再利用しました。
既存便の停留所順との照合で可能な範囲で進行方向を合わせていますが、旧停留所の標柱位置の完全な復元ではありません。
12件はバスマップに残る過去の停留所の代表座標です。道路の反対側の標柱などを区別しないため、GPS検知時に数十mの差が生じることがあります。

座標ごとの参照元・GTFS停留所ID・照合方法は `coordinate-sources.json` に記録しています。

出典:
- 北海道中央バスGTFS（提供された `hokkaido_chuo.zip`、HODA掲載、CC BY）
- バスマップ（国土数値情報などの公開データを加工して提供）: https://busmap.info/busstop/1006040/ 、https://busmap.info/busstop/11328/

確認日: 2026-11-05。過去の位置としての厳密な測量確認は行っていません。
